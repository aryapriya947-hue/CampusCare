# 🏫 CampusCare — Campus Issue Reporting System

CampusCare is a responsive web application designed to make campus issue reporting and tracking more organized. Students can report campus-related problems, set priorities, and track their status through a simple dashboard.

## 🌐 Live Demo

**[Visit CampusCare](https://aryapriya947-hue.github.io/CampusCare/)**

## ✨ Features

- 📝 **Report Issues:** Submit issues with a title, category, location, priority, and description.
- 📊 **Dashboard:** View issue statistics at a glance.
- 🔍 **Search and Filter:** Find issues using search and available filters.
- 🔄 **Status Tracking:** Track issues as Open, In Progress, or Resolved.
- 💾 **Local Data Storage:** Save demo issues in the browser using Local Storage.
- 📱 **Responsive Design:** Use the interface on different screen sizes.

## 🛠️ Tech Stack

- CSS3
- JavaScript

## 🚀 Getting Started

To run CampusCare locally:

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, use the Live Demo link above.

## ⚙️ How It Works

1. Open the application.
2. Enter the campus issue details in the reporting form.
3. Submit the issue.
4. Search, filter, and track issues using the dashboard.

## 📌 Current Limitations

- This is a frontend prototype.
- Issue data is stored in the current browser using Local Storage.
- Data is not shared between users or devices.
- There is currently no backend or database.

## 🔮 Future Improvements

- Backend and database integration.
- Student and administrator authentication.
- AI-based issue categorization.
- Notifications for issue status updates.
- Analytics to identify frequently reported campus problems.

## 🎯 Project Goal

The goal of CampusCare is to explore how web technologies can help organize campus issue reporting and improve visibility into issue status.
